# Roadster Run · Demo

以新款 Roadster（楔形切面车身、贯穿式灯带、深色玻璃座舱）为原型的 2.5D 横版过关 Demo。Three.js 实时渲染（PBR 车漆清漆层、IBL 反射、阴影、Bloom 泛光、MSAA），车辆模型、贴图、音效全部程序化生成，无外部资源。

## 运行

```bash
pnpm install
pnpm dev        # http://localhost:5188
pnpm build      # 类型检查 + 生产构建到 dist/
```

## 操作

| 按键 | 作用 |
| --- | --- |
| A / D 或 ← / → | 驾驶（地面上反向键减速后掉头） |
| Shift | 推进器加速（消耗推进剂） |
| Space | 跳跃 |
| Q | 真空吸附开关：可驶上墙面、倒挂天花板，空中会吸向最近的表面 |
| E | 喷气模式：W / ↑ 升力，A / D 水平推进；落地自动退出 |
| W / S | 普通模式空中控制车头俯仰 |
| R / P / M / H | 回到检查点 / 暂停 / 静音 / 帮助 |

支持手柄（左摇杆、A 跳跃、X 吸附、B 喷气、RT 升力）。

## 关卡流程（发射基地）

1. 起步直道 → 冲坡飞越等离子坑
2. 真空吸附爬上 16 m 垂直墙
3. 吸附跳上天花板倒挂行驶，绕过悬挂方块，到对岸按 Q 释放落下
4. 喷气飞越 90 m 峡谷，穿过三道移动激光门，中途可在补给柱降落
5. 吸附或喷气登上发射塔，冲过终点后自动点火升空

风扇（FAN）在墙面/天花板上会消耗，回到地面恢复；推进剂（THRUST）在喷气/加速时消耗，着地恢复。

## 代码结构

- `src/car/roadster-model.ts` — 关键帧切面放样车身（平面着色）、轮拱、玻璃座舱、星形气动轮毂、前后贯穿灯带、推进器喷流着色器
- `src/car/car-controller.ts` — 贴面行驶物理：轮下射线贴地、内角/外角过渡、空中吸附、喷气飞行
- `src/level/` — 关卡数据、圆角多边形碰撞世界、地形与道具构建、远景（城市、山脉、火箭发射台）
- `src/render/` — 渲染管线、程序化 PBR 贴图、粒子系统
- `src/game.ts` — 游戏状态、检查点、拾取、镜头、特效与 HUD 驱动
